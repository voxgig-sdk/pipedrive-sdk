Entities, SDKs, and tools

The API model defines entities, operations, fields, and endpoint contracts. SDK targets expose those operations in a programming language. Additional targets expose a command interface, an MCP server, or a data integration.

SDKs expose the API operations using each language’s conventions. Read the language reference for configuration and return values.
