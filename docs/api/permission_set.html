list

GET /permissionSets/{id}/assignments

Operation ID: getPermissionSetAssignments.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string | Yes | The ID of the permission set | | start | query | integer | No | Pagination start | | limit | query | integer | No | Items shown per page |

Responses

200: The assignments of a specific user ID

application/json

The response is object and object.

Example response:

{
  "data": [
    {
      "name": "Deals regular user",
      "permission_set_id": "f07d229d-088a-4144-a40f-1fe64295d180",
      "user_id": 10
    }
  ],
  "success": true
}
404: If the user ID has no assignments, then it will return NotFound

application/json

The response is any.
