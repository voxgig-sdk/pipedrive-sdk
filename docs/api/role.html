Operation ID: updateRolePipelines.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | integer | Yes | The ID of the role |

Request body

application/json

Property Type Required Description
visible_pipeline_ids object Yes The pipeline IDs to make the pipelines visible (add) and/or hidden (remove) for the specified role. It requires the following JSON structure: &#123; &quot;add&quot;: &quot;[1]&quot;, &quot;remove&quot;: &quot;[3, 4]&quot; &#125;.
