create

POST /activityTypes

Operation ID: addActivityType.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Request body

application/json

Property Type Required Description
color string No A designated color for the activity type in 6-character HEX format (for example FFFFFF for white, 000000 for black)
icon_key enum: task, email, meeting, deadline, call, lunch, ... Yes Icon graphic to use for representing this activity type
name string Yes The name of the activity type

Responses

200: The activity type was successfully created

application/json

The response is object and object.

Example response:

{
  "data": {
    "active_flag": true,
    "add_time": "2020-09-01 10:16:23",
    "color": "aeb31b",
    "icon_key": "camera",
    "id": 12,
    "is_custom_flag": true,
    "key_string": "video_call",
    "name": "Video call",
    "order_nr": 1,
    "update_time": "2020-09-01 10:16:23"
  },
  "success": true
}
