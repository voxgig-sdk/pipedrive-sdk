File

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /files create Add a file from computer or Google Drive and associate it with deal, person, organization, activity or product
POST /files/remote create Creates a new empty file in the remote location (googledrive) that will be linked to the item you supply - deal, person or organization
POST /files/remoteLink create Links an existing remote file (googledrive) to the item you supply - deal, person, organization
GET /files list Get data about all files uploaded to Pipedrive
GET /files/{id} load Get data about one specific file uploaded to Pipedrive
GET /files/{id}/download load success
DELETE /files/{id} remove Delete a file from Pipedrive
PUT /files/{id} update Update file name and description

Operation ID: addFile.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Request body

multipart/form-data

Responses

200: Update file name and description

application/json

Property Type Required Description
data object No The file data
data.active_flag boolean No Whether the user is active or not. false = Not activated, true = Activated
data.activity_id integer No The ID of the activity to associate the file with
data.add_time string No The date and time when the file was added/created. Format: YYYY-MM-DD HH:MM:SS
data.cid string No The ID of the inline attachment
data.deal_id integer No The ID of the deal to associate the file with
data.deal_name string No The name of the deal associated with the file
data.description string No The description of the file
data.file_name string No The original name of the file
data.file_size integer No The size of the file
data.id integer No The ID of the file
data.inline_flag boolean No Whether the file was uploaded as inline or not
data.lead_id string (uuid) No The ID of the lead to associate the file with
data.lead_name string No The name of the lead associated with the file
data.mail_message_id string No The ID of the mail message to associate the file with
data.mail_template_id string No The ID of the mail template to associate the file with
data.name string No The visible name of the file
data.org_id integer No The ID of the organization to associate the file with
data.org_name string No The name of the organization associated with the file
data.person_id integer No The ID of the person to associate the file with
data.person_name string No The name of the person associated with the file
data.product_id integer No The ID of the product to associate the file with
data.product_name string No The name of the product associated with the file
data.project_id integer No The ID of the project to associate the file with
data.project_name string No The name of the project associated with the file
data.remote_id string No The ID of the remote item
data.remote_location string No The location type to send the file to. Only googledrive is supported at the moment.
data.s3_bucket string No The location of the cloud storage
data.update_time string No The last updated date and time of the file. Format: YYYY-MM-DD HH:MM:SS
data.url string No The URL of the download file
data.user_id integer No The ID of the user to associate the file with
success boolean No If the request was successful or not
