create

POST /users

Operation ID: addUser.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Request body

application/json

Property Type Required Description
access array of object No The access given to the user. Each item in the array represents access to a specific app. Optionally may include either admin flag or permission set ID to specify which access to give within the app. If both are omitted, the default access for the corresponding app will be used. It requires structure as follows: [&#123; app: &#39;sales&#39;, permission_set_id: &#39;62cc4d7f-4038-4352-abf3-a8c1c822b631&#39; &#125;, &#123; app: &#39;global&#39;, admin: true &#125;, &#123; app: &#39;account_settings&#39; &#125;]
access[].admin boolean No Whether the user has admin access or not
access[].app enum: global, sales, campaigns, projects, account_settings, partnership, ... Yes The granular app access level
access[].permission_set_id string No The ID of the permission set
active_flag boolean No Whether the user is active or not. false = Not activated, true = Activated
email string Yes The email of the user
