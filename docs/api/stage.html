GET /stages/{id}/deals

Operation ID: getStageDeals.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | integer | Yes | The ID of the stage | | filter_id | query | integer | No | If supplied, only deals matching the given filter will be returned | | user_id | query | integer | No | If supplied, filter_id will not be considered and only deals owned by the given user will be returned. If omitted, deals owned by the authorized user will be returned. | | everyone | query | enum: 0, 1 | No | If supplied, filter_id and user_id will not be considered – instead, deals owned by everyone will be returned | | start | query | integer | No | Pagination start | | limit | query | integer | No | Items shown per page |

Responses

200: Get deals in a stage

application/json

Property Type Required Description

additional_data.limit integer No Items shown per page
additional_data.more_items_in_collection boolean No If there are more list items in the collection than displayed or not
additional_data.start integer No Pagination start
data array of object and object No The array of deals
success boolean No If the request was successful or not
