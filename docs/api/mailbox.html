Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | integer | Yes | The ID of the mail thread |

Request body

application/x-www-form-urlencoded

Property Type Required Description
archived_flag enum: 0, 1 No Whether this thread is archived or not. You can only archive threads that belong to Inbox folder. Archived threads will disappear from Inbox.
deal_id integer No The ID of the deal this thread is associated with
lead_id string (uuid) No The ID of the lead this thread is associated with
read_flag enum: 0, 1 No Whether this thread is read or unread
shared_flag enum: 0, 1 No Whether this thread is shared with other users in your company
