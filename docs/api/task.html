list

GET /tasks

Operation ID: getTasks.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | cursor | query | string | No | For pagination, the marker (an opaque string value) representing the first item on the next page | | limit | query | integer | No | For pagination, the limit of entries to be returned. If not provided, up to 500 items will be returned. | | assignee_id | query | integer | No | If supplied, only tasks that are assigned to this user are returned | | project_id | query | integer | No | If supplied, only tasks that are assigned to this project are returned | | parent_task_id | query | integer | No | If null is supplied then only parent tasks are returned. If integer is supplied then only subtasks of a specific task are returned. By default all tasks are returned. | | done | query | enum: 0, 1 | No | Whether the task is done or not. 0 = Not done, 1 = Done. If not omitted then returns both done and not done tasks. |
