POST /products/{id}/followers

Operation ID: addProductFollower.

Authentication: API key in the header (api_key) or oauth2 (oauth2).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | integer | Yes | The ID of the product |

Request body

application/json

Property Type Required Description
user_id integer Yes The ID of the user

Responses

201: Adds a follower to a product

application/json

Property Type Required Description
data object No
data.add_time string No The follower creation time. Format: YYYY-MM-DD HH:MM:SS
data.id integer No The ID of the follower
data.product_id integer No The ID of the product
data.user_id integer No The ID of the user that was added as follower
success boolean No If the response is successful or not

Example response:

{
  "data": {
    "add_time": "2019-12-24 12:02:04",
    "id": 1,
    "product_id": 2,
    "user_id": 10100010
  },
  "success": true
}
