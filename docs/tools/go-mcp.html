Configuration

Set the server URL and credentials for your environment. Enable only the features your application needs.

Features

  • Request/response capture ring buffer for debugging
  • Idempotency keys for safe retries of mutating operations
  • Statistics capture: per-operation counters and latency
  • Pagination signals for list operations
  • Client-side rate limiting via a token bucket
  • Automatic retry of transient failures with exponential backoff
  • In-memory mock transport for testing without a live server
  • Per-request timeout with transport abort

Tools

pipedrive_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "activity_field | activity_type | billing | call_log | channel | currency | deal | deal_field | file | filter | goal | lead | lead_field | lead_label | lead_source | legacy_team | mailbox | meeting | note | note_field | oauth | organization | organization_field | organization_relationship | permission_set | person | person_field | pipeline | product | product_field | project | project_board | project_phase | project_template | recent | role | stage | task | user | user_connection | user_setting | webhook"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: activity_field, activity_type, billing, call_log, currency, deal, deal_field, file, filter, lead, lead_field, lead_label, lead_source, legacy_team, mailbox, note, note_field, organization, organization_field, organization_relationship, permission_set, person, person_field, pipeline, product, product_field, project, project_board, project_phase, project_template, recent, role, stage, task, user, webhook.
